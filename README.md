# Data Analyst | Data Engineer

I'm a **Computer Science student** passionate about turning raw data into meaningful insights and building reliable data systems.

I enjoy working across the data lifecycle — from **data collection, cleaning, transformation, and analysis** to building **data pipelines, databases, dashboards, and machine learning solutions**.

I also love competing in **local and international hackathons**, where I build data-driven and software solutions under pressure.

### 📊 What I Work With

* **Data Analysis & Visualization** — Python, Pandas, NumPy, SQL
* **Data Engineering** — ETL/ELT pipelines, data transformation, databases
* **Databases** — PostgreSQL, MongoDB
* **Programming** — Python, TypeScript, JavaScript
* **Machine Learning** — Data preprocessing, exploratory analysis, predictive modeling
* **Web & Applications** — React, Next.js, Tailwind CSS
* **Tools & Design** — Git, Figma
